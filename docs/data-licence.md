# Data licence and attribution

The code of this project is under the [MIT licence](../LICENSE). The data belongs to the statistics office that publishes it. The terms of each office apply to the data.

## SiStat (Slovenia)

SURS data is free to use for any purpose, including commercial use, if you name SURS as the source. Refer to the [SURS copyright terms](https://www.stat.si/StatWeb/en/StaticPages/Index/Copyright).

The server adds the source to every result:

- `Source: SURS (Statistical Office of the Republic of Slovenia)` (English)
- `Vir: SURS (Statistični urad Republike Slovenije)` (Slovenian)

Each `get_table_metadata` and `query_table` result also has the table ID and a link to the table on SiStat.

If you calculate new figures from the data, you must say so, for example: `Source: SURS / Calculated by <you>`.

This project is not affiliated with or endorsed by SURS. Do not use the SURS logo or name in a way that suggests that SURS endorses your product.

## Statbank (Norway)

Statistics Norway (SSB) publishes its data under the [Creative Commons Attribution 4.0 licence (CC BY 4.0)](https://www.ssb.no/en/diverse/lisens). You can use it for any purpose, including commercial use, if you name Statistics Norway as the source.

The server adds the source and the licence link to every result:

- `Source: Statistics Norway (SSB), CC BY 4.0 (https://www.ssb.no/en/diverse/lisens)` (English)
- `Kilde: Statistisk sentralbyrå (SSB), CC BY 4.0 (https://www.ssb.no/diverse/lisens)` (Norwegian)

Each `get_table_metadata` and `query_table` result also has the table number and a link to the table on ssb.no.

If you change the data or calculate new figures, you must say so, for example: `Source: Statistics Norway (SSB) / Calculated by <you>`.

This project is not affiliated with or endorsed by Statistics Norway.

## Statistics Estonia

Statistics Estonia shares its open data under the [Creative Commons Attribution-ShareAlike 4.0 licence (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/). You can use it for any purpose, including commercial use, if you name Statistics Estonia as the source. If you change the data or make new data from it, you must share the result under the same licence.

The server adds the source and the licence link to every result:

- `Source: Statistics Estonia, CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)` (English)
- `Allikas: Statistikaamet, CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/)` (Estonian)

Each `get_table_metadata` and `query_table` result also has the table ID and a link to the table on andmed.stat.ee.

This project is not affiliated with or endorsed by Statistics Estonia.

## Other statistics offices

Before you add or publish a server for a different statistics office, read its terms of use. Some offices do not allow commercial use. You can run these offices as presets on your computer. We do not put them on the hosted endpoint.
