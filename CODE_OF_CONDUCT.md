# Code of conduct

This project uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful to all people in issues, pull requests and discussions.

To report unacceptable behaviour, use [private reporting](https://github.com/TadejPolajnar/pxweb-mcp/security/advisories/new) and start the title with "Conduct report". Only the maintainer can see these reports.

If the report is about the maintainer, use the [GitHub report form](https://support.github.com/contact/report-abuse).
