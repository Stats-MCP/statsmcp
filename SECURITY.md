# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Use [private vulnerability reporting](https://github.com/TadejPolajnar/pxweb-mcp/security/advisories/new) on GitHub. Tell us:

- the package or the hosted endpoint that has the problem
- the steps to make the problem occur
- the effect of the problem

We reply in 7 days or less.

## Supported versions

We fix security problems in the latest released version only.
